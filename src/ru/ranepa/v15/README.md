# Вариант 15. Планетарий

Статический `ShowUtils` создаёт объекты, меняет статусы, считает цену по типу и печатает список. Сам `Show` — анемичные данные с публичными полями, а сотрудники образуют отдельную иерархию.

**Схема классов**

- `Main` → `ShowUtils` (static)
- `ShowUtils` использует:
  - `ShowStore` — статический `HashMap`
  - `Notifier`
  - `if/else` по `kind`
- `Show` — данные без поведения
- `Employee` — абстрактный класс:
  - `Clerk`
    - `Trainee` — ломает `work()`
  - `Supervisor`
- `Actor` — интерфейс:
  - `Clerk`
  - `Supervisor` — кидает в `serve()` и `clean()`
